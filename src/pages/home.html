What is it?

A community overhaul of Evolve

Evolve is an asymmetrical multiplayer shooter, originally released in 2015, where a team of four hunters tracks and fights a single player-controlled monster that grows stronger over the course of a match. In 2018 it was rebooted as Evolve: Stage 2, which added new content and changes the original now called Legacy Evolve never received. Official support for the game later ended entirely.

Modded Evolve is a fan-made overhaul built on Evolve Stage 2. The plan for the future is for every hunter and monster to be rebalanced, abilities to be fixed and reworked, and cut content to be restored if possible.

Road Map

What the project hopes to achieve

Rebalance the whole roster

Every hunter and monster to be retuned from the ground up for fairer and more varied matches instead of a handful of dominant picks.

Rework broken kits

Abilities that were buggy, useless, or overpowered to be fixed and reworked so each character actually plays the way they’re meant to.

Restore lost content

If possible, content and changes cut prior to Stage 2 brought back into the game and made playable again.

Keep it alive

An ongoing patch cycle to keep fixing, tuning, and adding to the game long after official support has ended and with a full public reference for all of it.
